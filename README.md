# Mecra

Turkish Nuvio plugin.

## Install

Add this URL in Nuvio → Settings → Content & Discovery → Plugins:

```
https://raw.githubusercontent.com/mrrewilh/mecra/dist/manifest.json
```

`dist` is published by CI.

## Providers

HDFilmCehennemi, LiderFilm, DiziYou, YabancıDizi, ÇizgiMax, Anizium.

## Develop

```bash
npm install
npm run build
npm test
npm run dist
```
